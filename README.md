# design-with-clarity

把《Don't Make Me Think》和《写给大家看的设计书》的核心原则转化为可执行的界面设计与评审方法。

**目标：减少界面制造的猜测，让内容关系、操作含义和下一步一目了然。**

这是一个风格中立的 Agent Skill，可用于网页、应用界面，以及海报、文档等信息排版。它不会替代项目现有的设计规范，也不默认要求重构或新增功能。

## 适用场景

- 评审一个页面、表单或操作流程，定位用户可能困惑的地方。
- 优化布局、信息层级、文字、分组、对齐和反馈。
- 在实现 UI 时检查设计是否清楚、是否保留必要的信息。
- 审视海报、文档等静态内容的阅读顺序和视觉关系。

## 使用

将仓库作为支持 `SKILL.md` 的 Agent Skill 导入所用工具，然后在任务中调用：

```text
用 $design-with-clarity 评审这个上传页面。
保留现有功能和视觉风格，只给出最小有效修改。
```

或：

```text
用 $design-with-clarity 改进这个工作台。
优先解决理解、选择与状态反馈问题，不要为“简洁”隐藏必要数据。
```

## 八条原则

1. 找出界面额外制造的疑问。
2. 先支持扫读，再支持细读。
3. 让每次选择清楚。
4. 删除不帮助任务的内容。
5. 用亲密性表达归属。
6. 用对齐建立联系。
7. 用重复建立稳定预期。
8. 用对比表达有意义的差异。

这些不是固定的视觉配方。清晰不等于空旷，少点击不必然更好，一致性也不等于所有东西相同。

## 来源

本项目提炼自 Steve Krug 的 *Don't Make Me Think, Revisited*（第 3 版）和 Robin Williams 的 *The Non-Designer's Design Book*（第 4 版，中文常译《写给大家看的设计书》）。

这里提供的是**原创归纳与实践规则**，不是书籍的替代阅读版本。详细资料和区分见 [sources.md](references/sources.md)。
